Card setup

    Set up your Rukebox

    This page prepares the SD card so the Pi installs itself on its first start - nothing to type on the Pi.

    1. Flash "Raspberry Pi OS Lite" on the card with Raspberry Pi Imager.
    2. If you fill in Imager's settings (Wi-Fi, account), the user name must be "pi".
    3. Put the card back into this computer, then follow the steps here.

    This browser cannot write to the card directly: the page prepares a ZIP file whose contents you copy onto it.

    The SD card

    Choose the card's "bootfs" drive (the small partition the computer can open).

    Internet, for the installation

    Or reuse a saved configuration or a full backup (Configuration card)
    Drop the configuration file or the backup ZIP here, or click to choose it

    Your files (optional)

    They travel on the card. The card only has about 380 MB: a bigger library is sent from the interface after the installation.

    Write the card

      The card is ready

      1. Open rukebox-card.zip (just downloaded) and copy everything it holds to the card, replacing the files already there.
      2. Eject the card safely, put it into the Pi and switch it on.
      3. Leave this page open: it finds the Pi and takes you to it. The installation takes 15 to 30 minutes.
